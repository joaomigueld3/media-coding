# 🤖 Agent Guidelines — Media Coding Project

Se você é um agente de IA (Antigravity, Claude, Cursor, ChatGPT, etc.) trabalhando neste repositório:

1. **LEITURA OBRIGATÓRIA:** Consulte o arquivo [`HANDOVER.md`](HANDOVER.md) na raiz do projeto ANTES de propor alterações ou diagnosticar erros.
2. **EXECUTAR NO WSL:** O usuário está em um ambiente Windows + WSL2 Ubuntu. Todos os comandos Python e FFmpeg devem ser executados no WSL (`wsl python3 ...`).
3. **MÍDIAS:** Vídeos baixados e áudios processados ficam armazenados nas pastas `downloads/` e `videos/`.
4. **COLAB PRO:** Tarefas de IA pesadas (Real-ESRGAN, Whisper Large, Clonagem de Voz) devem ser preparadas para execução no Google Colab Pro com GPU.
